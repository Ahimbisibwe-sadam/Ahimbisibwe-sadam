# 🛠️ Setup — make it live in 5 minutes

## 1. Create the profile repo

GitHub shows a README on your profile **only** when the repo is named **exactly your username**.

1. Go to <https://github.com/new>
2. Name it: **`Ahimbisibwe-sadam`** (public, no README)
3. Push these files:

> ✅ **Already exists?** `github.com/Ahimbisibwe-sadam/Ahimbisibwe-sadam` is live (finally!) with GitHub's placeholder README — push over it with `git push -u --force origin main` to replace the placeholder without losing anything else.

```bash
cd /path/to/this/folder
git init -b main
git add .
git commit -m "✨ neon profile readme"
git remote add origin https://github.com/Ahimbisibwe-sadam/Ahimbisibwe-sadam.git
git push -u origin main
```

Done — open <https://github.com/Ahimbisibwe-sadam> and watch the neon.

> 💡 Everything is wired to the `Ahimbisibwe-sadam` handle. Changed your mind? Run `./scripts/personalize.sh <new-username> "<New Name>" <email>`.

## 2. Enable the snake (30 seconds)

The contribution-snake image is generated by GitHub Actions:

1. **Settings → Actions → General → Workflow permissions** → select **Read and write permissions** → **Save**
2. **Actions → 🐍 Neon Snake → Run workflow** (on `main`)
3. Wait ~1 min → an `output` branch appears → refresh your profile.

The snake card is a `<picture>`: dark mode gets the neon-cyan snake, light mode the magenta one.

## 2b. Enable the metrics infographic (30 seconds, optional but impressive)

A second workflow generates a full infographic (activity, languages, habits) and commits it to a `metrics` branch:

1. **Actions → 📊 GitHub Metrics → Run workflow** (permissions from step 2 apply)
2. Wait ~1 min → the `metrics` branch appears → the `📈 self-hosted metrics` section lights up.

## 3. What needs the network (and what's bulletproof)

| Element | Source | Notes |
|---|---|---|
| Banner, ticker, typewriter, support card, footer | `./assets/*.svg` | ✅ Own repo — always works |
| GitHub stats + top languages | github-readme-stats.vercel.app | ⚠️ Shared public instance; can rate-limit (503). Retry after a minute |
| Streak | streak-stats.demolab.com | ✅ Usually stable |
| Dev quote | quotes-github-readme.vercel.app | ✅ Dynamic, changes on refresh |
| Snake | `output` branch in your repo | ✅ Needs step 2 |
| Metrics infographic | `metrics` branch in your repo | ✅ Needs step 2b |
| Mermaid workflow diagram | rendered natively by GitHub | ✅ No external service |
| Badges | shields.io, skillicons.dev, komarev.com | ✅ Stable |

GitHub's camo proxy **caches images for ~24h**, so after edits your profile may show the old banner for a while. That's normal — and a URL tweak (adding `&v=2`) busts the cache immediately if you're impatient.

## 5. Style notes

- **Palette — green · white · blue:** neon green `#2BFF88`, white `#F4FEFF`, electric blue `#00B3FF`, on navy-black `#03060C`/`#04070F`. Search-replace these three tokens across `assets/*.svg` + `README.md` (stats/badges use them without the `#`) to reskin the whole profile.
- The SVG banner is a **dark card on purpose** — it looks intentional in both GitHub light and dark themes.
- Best viewed in **GitHub dark mode** (`Settings → Appearance → Dark`).
- All animations are SMIL inside `<img>` SVGs — no JavaScript, so GitHub renders them safely.

## 6. Troubleshooting

| Symptom | Fix |
|---|---|
| Snake image 404 | Run the 🐍 Neon Snake workflow once (step 2) |
| Stats card shows 0s / breaks | New account — data appears once repos/commits exist; 503 = vendor busy |
| Banner not updating | GitHub camo cache — add `?v=2` to the img `src` |
| Actions job fails on permissions | Redo step 2's *Read and write permissions* |
